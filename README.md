📋 E-ABSENSI SENEXUS

«Web-based Attendance Management System»

E-ABSENSI SENEXUS adalah aplikasi absensi berbasis web yang dibuat untuk membantu proses pencatatan dan pengelolaan kehadiran siswa secara digital.

Project ini dibuat sebagai bagian dari proses belajar Web Development, Backend, Database, dan Software Engineering.

---

✨ Features

- 🔐 Admin Login
- 👨‍🎓 Student Login
- 📝 Student Attendance
- 📊 Attendance Dashboard
- 📋 Attendance Data Management
- 🔎 Student Data
- ☁️ Cloud-based Data Storage

---

🛠️ Technologies

Frontend

- CSS

Backend

👥 User Roles

👨‍💼 Admin

Admin dapat:

- Melihat data siswa
- Melihat data absensi
- Mengelola data kehadiran
- Memantau aktivitas absensi

👨‍🎓 Student

Siswa dapat:

- Login menggunakan identitas siswa
- Melakukan absensi
- Melihat informasi kehadiran
